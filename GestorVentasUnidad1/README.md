## 📝 Descripción del Proyecto
Aplicación de consola en .NET 8 para la gestión básica de inventarios y ventas en comercios pequeños. Permite registrar nuevos productos, consultar existencias con alertas de bajo stock, realizar ventas calculando desgloses de subtotal, descuento (10%) e IVA (19%), y generar reportes con estadísticas de caja diaria.

El desarrollo se realizó bajo las reglas de la Unidad 1: **sin Programación Orientada a Objetos (POO)** ni bases de datos, utilizando únicamente métodos estáticos (`static`), manejo seguro de excepciones (`TryParse`) y colecciones dinámicas (`List<T>`).
